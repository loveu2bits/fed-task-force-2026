# 近期动态时间线板块 — 设计文档

日期：2026-07-23
状态：已获用户批准

## 背景

站点展示美联储 2026-07-09 宣布的五个货币政策特别工作组共 15 位外部联合负责人。用户希望追踪这些成员自宣布以来（2026-07-09 至 2026-07-23）的公开活动与发言，并在网页中以时间线形式展示。先在本地更新预览，验证后再部署。

## 范围决策（用户已确认）

- **收录范围**：所有公开露面与发言（不限于货币政策相关），含演讲、媒体专访、专栏文章、播客、公开出席活动。
- **展示形式**：新增独立「近期动态」板块，按日期倒序的时间线信息流。
- **真实性要求**：只收录有可核验公开来源的条目，每条附原始链接；查无动态的成员如实标注，不编造。

## 数据层（data.js）

新增顶层字段 `activities`，每条记录：

```js
{
  date: "2026-07-22",        // ISO 日期
  memberId: "raghuram-rajan", // 对应 members[].id
  type: "专访",               // 演讲 / 专访 / 专栏 / 播客 / 出席
  title: "彭博专访：…",
  summary: "发言要点，1-2 句",
  url: "https://…"           // 原始来源链接
}
```

`updated` 字段更新为 2026-07-23。

## 展示层

- `index.html`：在「成员档案」之后、「资料来源」之前新增 `<section id="activity">`；顶部导航增加「动态」链接；总览的「资料更新」日期改为 2026.07.23。
- `app.js`：新增 `renderActivities()`，按日期倒序分组渲染时间线；圆点与左边线沿用成员所属工作组的主题色（`--group-color`）；条目含类型徽章、标题、要点、来源外链；点击人名跳转对应成员档案（复用 `focusMember`）。
- 板块末尾注明「其余 N 位成员在此期间无公开动态记录」，使无动态这一事实可见。
- `styles.css`：新增时间线样式，沿用现有设计令牌（字体、间距、卡片圆角、组色变量），响应式与深浅对比与现有一致。

## 内容研究

对 15 位成员逐一做网络检索（并行派发研究 agent），时间窗口 2026-07-09 至 2026-07-23。每条候选动态须附可访问的原始 URL 与日期；无法核验的一律不收。

## 构建与验证

1. 修改 `data.js` / `index.html` / `app.js` / `styles.css`。
2. 运行 `node build-single-file.mjs` 重新生成嵌入版 HTML。
3. 本地 HTTP 服务预览，确认时间线渲染、组色、筛选与既有功能无回归。
4. 用户确认后再 commit / push（push 即自动部署到 GitHub Pages）。

## 不做的事（YAGNI）

- 不做自动抓取/定时更新管线（手动维护 activities 数据）。
- 不做按类型筛选、分页、成员维度聚合视图。
- 不在成员档案内重复嵌入动态（本次仅时间线单入口）。
